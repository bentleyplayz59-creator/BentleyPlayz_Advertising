# Bentley's Advertising

A Stardew Valley SMAPI mod by Bentley Playz.

## Features

- Real-time randomized advertisements.
- Multiple variations per advertiser.
- Randomized advertising letters.
- Custom on-screen advertising pop-ups.
- Business and shop advertising.
- Custom advertising HUD menu.
- Gold-based advertising subscriptions.
- Configurable advertising settings.

## Project Architecture

- One main C# DLL.
- config.json for player settings.
- advertisements.json for advertisement definitions.

## Compatibility

Stardew Valley 1.6
SMAPI
Android compatibility testing planned.
